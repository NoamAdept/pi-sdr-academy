Pi SDR Academy

How to use the lab — student playbook & instructor notes

Offline dojo for systems, DSP, and software-defined radio on a Raspberry Pi (or Mac for development). You earn belts by finishing dojos in order. Day-to-day scoring is ./check — you do not need to type academy … for normal play.

1. One-time setup (Mac)

cd /Users/noamyakar/Desktop/pi-sdr-academy
source .venv/bin/activate
export ACADEMY_CURRICULUM=$PWD/curriculum
export PYTHONPATH=$PWD/platform

# Optional — installs short commands on PATH: next, hint, submit, status, dojos
pip install -e ./platform

On a prepared Pi image, instead source /opt/academy/academy.env (or your install path) after offline_bundle/install.sh.

2. Everyday student loop

python -m academy              # home screen + belt status
# or:  dojos

python -m academy next         # load next challenge
cd ~/challenge                 # or /challenge on Pi
# … solve the challenge …

./check                        # grade + score in one step
python -m academy next         # continue

If you found a flag in the files

./submit 'flag{...}'           # quotes required in zsh

Useful local commands (inside the challenge folder)

3. Dojo map in the browser

python -m academy serve --port 8081
# open http://127.0.0.1:8081/
  • Click a dojo card to see modules, every challenge, and a short description.
  • Core dojos unlock in belt order (white → black).
  • Side quests are optional and do not block the core path.

5. How flags work

  • Each next / start mints a session flag with a random suffix (e.g. flag{name_a1b2c3}).
  • The flag file stays empty until you earn it via ./check (or you paste a found flag).
  • Checkers do not hardcode the live flag. Do not distribute instructor solutions to students.

6. Instructor guides (password protected)

Keep unlocked instructor material off student machines and Pi images. 
# Unlock (password from env, prompt, or instructor/.instructor_password)
python3 scripts/unlock_instructor_guides.py
open instructor/INDEX.md

# Lock again before sharing the repo / imaging a Pi
python3 scripts/lock_instructor_guides.py

After editing challenges, regenerate then re-lock:

python3 scripts/generate_instructor_guides.py
python3 scripts/lock_instructor_guides.py

8. Raspberry Pi (later)

  1. Copy the repo (and offline bundle) to the Pi.
  2. Run offline_bundle/install.sh.
  3. source the generated academy.env.
  4. Same student loop: next → work in /challenge → ./check.
  5. Do not unlock instructor guides on student images.
