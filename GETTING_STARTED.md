# Getting started (closed network)

You need **python3**. Nothing else. No pip. No internet.

```bash
tar -xzf pi-sdr-academy.tar.gz
cd pi-sdr-academy
./run.sh
```

Open the URL (usually http://127.0.0.1:8080/).

1. Read the intro
2. **Enter the lab**
3. **Start** → files land in `./challenge`
4. Open that folder, read `README.txt`, solve it
5. **Done**

If `./run.sh` says it cannot find python3, install only the system `python3` package from your OS media — still no pip.
