# Getting started

You need **python3**. Nothing else.

```bash
./run.sh
```

Open the URL it prints (usually http://127.0.0.1:8080/).

## The loop

1. Press **Start** — challenge files land in `./challenge`
2. Open `./challenge`, read `README.txt`, solve the puzzle
3. Press **Done** in the browser

If you find a `flag{…}` string, you can paste it instead of pressing Done.

Belts unlock in order (white → blue). Take a **Hint** only when stuck.

## Portable pack

```bash
tar -xzf pi-sdr-academy.tar.gz
cd pi-sdr-academy
./run.sh
```

Same loop. No internet. No pip.
