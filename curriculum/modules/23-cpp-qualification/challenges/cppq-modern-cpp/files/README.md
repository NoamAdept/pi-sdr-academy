# One modern C++17 project

Complete `scanner.cpp` and run `./check`.

Use all five requested tools in the finished program:
- `auto` for inferred local types;
- a range-based `for`;
- the scoped values of `enum class Signal`;
- a `constexpr` classifier that passes the supplied `static_assert`;
- `std::array` for the fixed levels.

CMake is covered in Module 6, RAII and smart pointers in Module 5, and broader STL practice in `cpp-stl`.
