Meet Your Progress Branch
=========================

What is git?
------------
Git is a tool that remembers versions of files. A **branch** is a named
timeline — like your own notebook inside a shared cabinet.

What this lab does for you
--------------------------
When the academy starts the **first time**, it creates a progress repository
(academy-progress.git). Your clears are saved on a branch:

  progress/<your-username>

You do not need to type git commands for everyday solving — the lab updates
that branch automatically. This challenge just helps you *see* it.

Steps
-----
1. Press Start.
2. Run:  ./whoami_branch
3. Put that exact branch name into answer.txt (one line).
4. Run:  ./check
5. Press Done in the dojo.
