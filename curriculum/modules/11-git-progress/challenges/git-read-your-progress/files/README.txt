Read Progress From Your Branch
==============================

Your clears are stored as a small JSON file on your git branch:

  progress/<you>  →  progress.json

This challenge uses a helper so you do not need advanced git yet.

Steps
-----
1. Press Start.
2. Run:  ./peek_progress
   You should see JSON text (curly braces, quotes).
3. Count how many challenges have "solved": true.
4. Write that number into cleared.txt (just the number).
5. Run:  ./check
6. Press Done.
