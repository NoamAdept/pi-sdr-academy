Watch a Variable Change
=======================

Goal
----
Break at inspect_here; continue until the fourth call; read level.

Deliverable
-----------
  answer.txt — level as a decimal integer

Steps
-----
1) Press Start, then: ./run
2) GDB: break inspect_here → run → continue (three more times) → print level
3) Write answer.txt, then: ./check
4) Press Done when check passes.
