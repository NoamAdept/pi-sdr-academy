Hello, Terminal
===============

No Linux experience? Perfect — this challenge is for you.

What is a terminal?
-------------------
A terminal is a plain window where you type short commands
and the computer answers with text. Nothing to click. Just type.

What to do
----------
1. In the dojo web page, press **Start**.
2. Open a **Terminal** app (black/white text window).
   Ask your instructor if you cannot find it.
3. Type this and press Enter:

     cd challenge

   (If that fails, the Start button showed a Folder path — cd to that.)
4. Type:  pwd     ← “print working directory” = where am I?
5. Type:  ls      ← “list” = what files are here?
6. Type:  cat hello.txt
7. Type:  cat flag.txt
8. Copy the flag{...} line. Paste it in the dojo and press Go — or press Done.

Cheat sheet:  cat CHEAT_SHEET.txt
