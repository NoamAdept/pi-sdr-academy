Launch C++ std::thread Workers
==============================

Goal
----
Finish `parallel_add` in workers.cpp using `std::thread` and `std::mutex`
so many workers safely produce `n_threads * per_thread`.

Workflow
--------
1. Press Start, then run `./run`.
2. Fill in the TODO in workers.cpp.
3. Run `./check` until it passes, then press Done.

Offline, one workspace. Compile flag: `-pthread`.
