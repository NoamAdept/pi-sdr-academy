Spawn a Python Child Process
============================

Goal
----
Finish `run_echo(msg)` in worker.py so it starts a **child process**
(via subprocess) that prints `msg`, then return the child's stripped stdout.

Workflow
--------
1. Press Start, then run `./run`.
2. Edit worker.py — do not just return msg from the parent.
3. Run `./check` until it passes, then press Done.

Offline, one workspace, no network.
