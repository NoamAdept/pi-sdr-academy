Fork a C++ Child Process
========================

Goal
----
Finish controller.cpp: fork a child that prints `child_ok`, wait in the parent,
and print `child_status=0`.

Workflow
--------
1. Press Start, then run `./run`.
2. Fill in the TODO in controller.cpp.
3. Run `./check` until it passes, then press Done.

Offline, one workspace, no network. Needs `c++` or `g++`.
