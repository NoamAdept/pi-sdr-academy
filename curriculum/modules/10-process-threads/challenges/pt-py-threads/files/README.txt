Share Work Across Python Threads
================================

Goal
----
Finish `parallel_add(n_threads, per_thread)` so many threads safely add to one
shared counter and you return the final total.

Workflow
--------
1. Press Start, then run `./run`.
2. Use `threading.Thread` and a `Lock` in counter.py.
3. Run `./check` until it passes, then press Done.

Offline, one workspace, no network.
