# Copy with File Descriptors

## Goal
Complete `copy.c` using `open` / `read` / `write` / `close` (not stdio copy helpers).

## Steps
1. Press Start, then run `./run` (builds / prepares the local fixture).
2. Open the starter and finish the TODO comments.
3. Run `./check` until it passes, then press Done.

Offline, one workspace, no hardware.
